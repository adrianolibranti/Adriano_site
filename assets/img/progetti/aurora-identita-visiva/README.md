# Asset — Aurora (Identità visiva)

Metti qui le immagini reali del progetto "Aurora" (progetto-aurora.html).
Nomi file attesi (rispettali esattamente, oppure cambia i percorsi
nel file HTML se preferisci nomi diversi):

- `cover.jpg` — immagine di copertina (16:9), quella che appare anche
  come anteprima nella card in brand-comunicazione.html
- `galleria/01.jpg` ... `galleria/06.jpg` — le immagini della galleria
  (loghi, palette colori, biglietti da visita, packaging, applicazioni...)
  Aggiungine o togline quante ne vuoi: in progetto-aurora.html basta
  copiare/rimuovere un `<div class="project-gallery__item">` per ognuna.

Finché non ci sono immagini vere, il sito mostra dei gradienti
segnaposto (nessun file mancante da temere).
